# Curso em Video - Projetos

Este repositório contém os projetos desenvolvidos durante as aulas do Curso em Vídeo.

## ✨ Sobre os Projetos

Cada projeto demonstra diferentes aspectos do desenvolvimento web com HTML, CSS e possivelmente JavaScript. Alguns projetos também referenciam PHP, mas não incluem arquivos dessa tecnologia.

### 🔮 Lista de Projetos

- **projeto-android**: Site sobre a história do mascote do Android.
  ![Projeto  - Android](https://github.com/user-attachments/assets/437c0edc-b90f-4e6b-b9a4-27d6779c63c0)

- **projeto-cordel**: Apresentação visual de um cordel moderno.
  ![Projeto  - Cordel](https://github.com/user-attachments/assets/fdca6466-b958-4cda-8683-098e0d85fa40)

- **projeto-login**: Interface de uma tela de login.
  ![Projeto  - Login](https://github.com/user-attachments/assets/9bddd6f8-7cee-4c58-983d-9c32e3048ab2)

- **projeto-social**: Agregador de perfis de redes sociais.
  ![Projeto  - Social](https://github.com/user-attachments/assets/9f4fd858-0f3b-49d2-816d-c9a29ba09bcc)


## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3

## 📚 Como Utilizar

1. Clone este repositório:

   ```bash
   git clone https://github.com/jaojogadez/curso-em-video-projetos.git
   ```

2. Acesse o diretório do projeto desejado:

   ```bash
   cd curso-em-video-projetos/projeto-android
   ```

3. Abra o arquivo `index.html` no navegador.

## 🔍 Visão Geral dos Projetos

- **projeto-android**: Leia sobre a história do mascote Android, com imagens e vídeos incorporados.
- **projeto-cordel**: Role a página para visualizar um cordel moderno estilizado.
- **projeto-login**: Interface de login funcional, mas sem backend implementado.
- **projeto-social**: Exibe links para redes sociais dentro de um iframe.
