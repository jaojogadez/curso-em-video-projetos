# curso-em-video-projetos

Meus projetos desenvolvidos em aulas do curso em video.

## Description

This repository contains a collection of web development projects created while following the "Curso em Video" course.  Each project demonstrates different aspects of HTML, CSS, and potentially some JavaScript (although PHP is referenced in `projeto-login/index.html`, no PHP files were provided for analysis).

## Projects

*   **projeto-android:** A website about the history of the Android mascot.
*   **projeto-cordel:** A website displaying a modern "cordel" (Brazilian folk poetry) in a visually engaging way.
*   **projeto-login:** A login page interface.
*   **projeto-social:** A simple social media profile aggregator.

## Technology Stack

*   HTML5
*   CSS3
*   (Potentially) JavaScript
*   (Potentially) PHP (referenced in `projeto-login`, but no PHP files included)

## Prerequisites

To run or modify these projects, you will need:

*   A web browser (Chrome, Firefox, Safari, etc.)
*   A text editor or IDE (VS Code, Sublime Text, Atom, etc.)
*   (If using PHP) A local PHP development environment (e.g., XAMPP, WAMP)

## Installation Instructions

Since these projects are primarily HTML and CSS based, no formal installation is required.  You can simply clone the repository or download the files and open the `index.html` file in each project's directory with your web browser.

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/jaojogadez/curso-em-video-projetos.git
    ```

2.  **Navigate to a project directory:**

    ```bash
    cd curso-em-video-projetos/projeto-android
    ```

3.  **Open the `index.html` file in your browser.**

    Repeat steps 2 and 3 for each project.

## Usage Guide

Each project is self-contained.  Simply opening the `index.html` file will display the project in your browser.

*   **projeto-android:**  Browse the page to read about the history of the Android mascot. The page includes text, images and an embedded YouTube video.
*   **projeto-cordel:** Scroll through the page to read the "cordel" poem, which is visually enhanced with background images.
*   **projeto-login:**  You can interact with the login form.  However, since the `cadastro.php` file is not provided, the form submission will not actually process any data.  This project is a front-end implementation only (without backend functionality, unless you implement `cadastro.php` yourself).
*   **projeto-social:** This project emulates a simple social media profile page with links to different social media platforms. Click on the social media logos to load the corresponding pages (home, Github, Instagram, Facebook, Youtube) within the iframe.
